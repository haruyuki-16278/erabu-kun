# macOSブラウザプロファイル選択アプリ 実装計画 (仕様書)

## 1. 目的と概要
本アプリは、外部アプリ（Slackなど）からWebリンク（http/https）をクリックした際に、どのWebブラウザ・どのプロファイルで開くかをポップアップで選択できるmacOS専用のユーティリティアプリです。
Xcodeのプロジェクトファイル（`.xcodeproj`）に依存せず、ターミナル（コマンドライン）からビルドできるスクリプトを提供します。

## 2. 要件定義（仕様）

### 2.1. リンクのインターセプト機能
* macOSのデフォルトブラウザとして設定可能にし、他のアプリでhttp/httpsリンクがクリックされたイベント（`openURL`）をアプリがフックします。

### 2.2. プロファイル選択ポップアップ機能
* リンクがクリックされた際、マウスポインタの近く（または画面中央）に一時的なポップアップウィンドウを表示します。
* ポップアップには以下の内容を表示します。
  * **[NEW] UIの大型化と縦スクロール化**: 選択肢が増えることに対応し、ウィンドウサイズを大きくし、ブラウザの選択肢を縦方向のスクロールリストとして表示します。
  * 選択可能なブラウザのアイコンと、そのプロファイル名（例: Chrome - "Work", Edge - "Personal"）のリスト。
* **[NEW] 対応ブラウザの拡充**: Google Chrome, Chrome Beta, Chrome Canary, Microsoft Edge, Vivaldi, Safari, Firefox, Brave, Opera 等の一般的なブラウザがインストールされているか動的チェックし、一覧に統合します。
* **キーボード操作・キャンセル操作:**
  * **Enterキー押下**: あらかじめ設定された「デフォルトのブラウザ・プロファイル」でリンクを開きます。
  * **ポップアップ外でのクリック**または**Escキー押下**: ポップアップを閉じ、設定された「デフォルトのブラウザ・プロファイル」でリンクを開きます。
  * 矢印キー（上下等）でリストから選択してEnterを押した場合、そのプロファイルで開く機能も実装します。

### 2.3. 常駐機能・設定画面
* ドックにはアイコンを表示させず（バックグラウンドモード）、メニューバー（ステータスバー）に常駐します。
* メニューバーアイコンをクリックし、「設定 (Preferences)」を選ぶと設定画面が表示されます。
* **設定画面の機能:**
  * 「デフォルトで使用するブラウザ」と「デフォルトで使用するプロファイル」の選択・保存機能。
  * 本アプリをOSのデフォルトブラウザにするボタン。
  * **[NEW] カスタムブラウザの追加機能**: 自動検知されていない任意のアプリケーション（.app 形式）を、一覧に表示して利用可能にする手動登録および削除機能。

### 2.4. ビルド要件（CLIビルド）
* コマンドラインからSwiftコンパイラ（`swiftc`）を利用し、手動で `.app` バンドルのディレクトリ構造を組み上げるスクリプト（`build.sh` 等）を作成します。
* これにより、ユーザーはターミナルで `./build.sh` を実行するだけで完成品の `BrowserSwitcher.app` を生成できます。

## 3. アプリケーション設計（コンポーネント構成）

1. **`App.swift` / `AppDelegate.swift`**
   * エントリポイント。メニューバーへの常駐設定、デフォルトブラウザとしての動作宣言などを行います。
2. **`URLHandler.swift`**
   * OSからURLが渡されたときに、ポップアップを表示するトリガーとなる役割を担います。
3. **`PopupView.swift` (SwiftUI)**
   * ブラウザ/プロファイル一覧を表示するメインのポップアップ画面です。
4. **`SettingsView.swift` (SwiftUI)**
   * メニューバーから呼び出される設定画面です。`UserDefaults` で設定を読み書きします。
5. **`ProfileScanner.swift`**
   * ChromeやEdgeなどの設定フォルダ（`Local State` ファイルなど）を読み取り、インストールされているプロファイルを動的に一覧化します。
6. **`BrowserLauncher.swift`**
   * 選択されたプロファイルを指定したターミナルコマンド（`open -n -a "Google Chrome" --args --profile-directory=...`）を手配し、実行します。
7. **`Info.plist`**
   * アプリ名、URLスキームの宣言（http/https登録）、バックグラウンド実行（`LSUIElement = YES`）などを定義したメタファイルです。
8. **`build.sh`**
   * `swiftc`コンパイルと `.app` パッケージ構築を自動化するシェルスクリプトです。

## 5. 検証手順 (Verification Plan)

### 自動/手動検証手順
1. **ビルドの検証**
   * ターミナルから `./build.sh` を実行し、`build/BrowserSwitcher.app` が正常に生成されることを確認します。
2. **実行の検証**
   * ターミナルで `open build/BrowserSwitcher.app` を実行し、メニューバーにアイコンが追加されることを確認します。
3. **設定画面の検証**
   * メニューバーアイコンから「Settings(設定)」を開き、ブラウザとプロファイルの取得・保存ができるか確認します。
4. **ブラウザフックとポップアップの検証**
   * ターミナルから `open -a "BrowserSwitcher" "https://example.com"` のように本アプリにURLを直接渡し、ポップアップが表示されるか確認します。
   * ポップアップ外をクリック、またはEnterキーを押した時に、デフォルト指定したブラウザ・プロファイルで想定通りにURLが開くか確認します。
